# listai-drafts

Публичный репозиторий автоматики постов канала listai.pro. Секретов здесь нет, токен бота лежит только на сервере.

Как работает каждый день:
1. 06:00 UTC облачный агент кладёт `draft.json` (новость дня) и `images/ДАТА.jpg`.
2. 06:50 UTC сервер запускает `daily.py`: выбирает пост дня (`queue/ДАТА.json`, «инструмент дня», иначе `draft.json`), присылает превью владельцу в личку.
3. В `publish_time_lisbon` (config.json, сейчас 10:05 по Лиссабону) `daily.py` сам публикует пост в канал.
   Если у «инструмента дня» не открывается `requires_url` (карточка не опубликована), выходит новость дня.
4. Отмена дня: добавить дату в `hold.json` (`{"dates": ["2026-10-28"]}`).

Формат `queue/ДАТА.json` (даты по Москве): `post_html`, `image_file`, `button_text`, `button_url`, `requires_url`, `facts`.
Выключить автопубликацию: `"publish_channel": false` в config.json.
