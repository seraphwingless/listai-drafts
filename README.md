# listai-drafts

Публичный репозиторий ежедневного процесса постов канала listai.pro.

- `draft.json` — черновик на сегодня. Его пишет облачный агент (утром), читает сервер.
- `daily.py` — запускается на сервере: берёт `draft.json`, собирает картинку (`make_post_pic.py`) и присылает черновик владельцу в личку через бота (`telegram_post.py`). В канал сам не публикует.
- `assets/`, `backgrounds/` — шрифт Roboto, логотип и фоны для картинок.

Формат `draft.json`:

    {"date": "2026-10-27", "status": "ready" | "skip", "image_type": "news",
     "image_title": "...", "post_html": "...", "button_url": "https://listai.pro/katalog/",
     "facts": ["утверждение — источник, дата"], "note": "причина пропуска (для status=skip)"}

Секретов в репозитории нет и быть не должно: токен бота хранится только на сервере.
